# Contributing

This companion welcomes precise corrections, clearer explanations, and better navigation. Research credit remains with the paper authors.

For a factual correction, give the exact paper version, section, PDF page, and relevant table/figure. Explain the existing error and proposed wording. For a quantitative change, retain the metric, evaluation population, failure treatment, and selection protocol. Label interpretation and proposed experiments explicitly.

Changes should update any related entries in metadata/claims.json, source metadata, and README. Do not present new measurements as author-reported results. Do not import the official code or paper assets without reviewing license and attribution requirements.

Run `python scripts/validate_repository.py` before submitting changes. Review affected external links and inspect figure pixels if a claim depends on a figure. These checks assess the companion only; they do not reproduce the study.

Later arXiv versions should get a deliberate version update and a description of material differences. Keep the source version visible throughout the repository.
